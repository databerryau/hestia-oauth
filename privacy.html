Privacy policy

Last updated 22 October 2026.

Hestia is a private assistant used by a single household. It has one user, and it is not offered to the public.

What it accesses

With the account owner's consent, Hestia uses Google APIs on its own Google account, requesting only the scopes it needs.

Where data goes

Data is processed on the household's own computer. OAuth tokens are stored there and never published. Content may be passed to the AI model provider that powers the assistant, solely to carry out the household's own requests. Data is not sold, shared with third parties for any other purpose, or used for advertising.

Google user data

Hestia's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time from Google Account → Third-party connections, which stops all further access.
